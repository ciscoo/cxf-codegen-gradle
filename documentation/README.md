# CXF Codegen Documentation

Documentation built with [VitePress](https://vitepress.dev/).

## Prerequisites

In addition to the overall project prerequisites, the following is required to build the documentation:

- Node.js (refer to `.nvmrc` for version)

## Development

To run the documentation with a dev server, run the following command:

```shell
./gradlew :documentation:devDocs
```

To preview the documentation that will be deployed:

```shell
./gradlew :documentation:previewDocs
```
